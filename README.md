📋 Sistema de Automação de Manutenção – Google Sheets

Este projeto consiste em scripts desenvolvidos para Google Sheets com o objetivo de automatizar o registro e a consulta de manutenções realizadas em equipamentos.

🚀 Objetivo

Automatizar os dados preenchidos em um Formulário de Transferência, enviando essas informações para:

Uma segunda via de comprovação de manutenção

Um registro automático no Google Drive em formato de planilha

Isso permite um controle organizado das manutenções realizadas, facilitando consultas por mês, ano ou histórico completo, eliminando a necessidade de registros manuais.

⚙️ Script 1 – Registro Automático

O primeiro script é responsável por:

✔ Capturar os dados preenchidos no formulário
✔ Gerar automaticamente a segunda via como comprovante de manutenção
✔ Armazenar os dados em uma planilha no Google Drive
✔ Manter um histórico organizado por período

Com isso, é possível saber exatamente quais manutenções foram feitas em qualquer data passada.

🔍 Script 2 – Consulta de Registros

O segundo script, chamado Consulta, complementa o primeiro.

Ele permite buscar informações registradas de forma rápida e prática.

Como funciona:

Basta digitar um termo relacionado ao que deseja encontrar.

Exemplo:

Se quiser saber todos os equipamentos que passaram por manutenção do modelo F50, basta digitar:
F50

O script irá retornar todos os registros correspondentes encontrados nas planilhas armazenadas no Drive.

🧩 Estrutura Necessária

Os scripts utilizam um modelo próprio de planilha e uma formatação específica para funcionar corretamente.
É importante manter o padrão original para garantir que o sistema opere sem erros.

✅ Benefícios

Automação total do registro de manutenções

Redução de erros manuais

Histórico completo armazenado em nuvem

Consultas rápidas e práticas

Organização por período (mês/ano)
